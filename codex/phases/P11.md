# P11 — Enterprise, operations, billing

**Objective:** Harden tenancy, metering and governance.

## Build work
SSO/SCIM if licensed; policies/approvals; auditing; data retention/erase; ledger reconciliation, admin operations and incident dashboards.

## Required proof
Role/PII/retention tests, ledger reconciliation and export/access audit.

## Stop condition / risks
No compliance certifications claimed without audit.

## How Codex must report
Describe real code changes, migrations, API endpoints, UI routes, security/compatibility behavior, exact commands and outputs, screenshots/traces and gaps. Update BUILD_LOG.md and acceptance matrix; do not invent passing tests. Open one reviewable PR for this phase.

## Completion criterion
Testable and repeatable in configured local/staging environment, authorized, observable and documented. Any external unavailable integration stays BLOCKED_EXTERNAL, not COMPLETED.
